📖 Basic MML Reference

Notes

C D E F G A B
Use + or # for sharps, - for flats (e.g. C+, D-)

Length

l4 = quarter note
l8 = eighth note
Use "." to extend (e.g. l8.)

Volume / Tempo

v8 = medium volume
t120 = tempo 120 BPM

Octave / Tie

o4 = octave 4
& = tie notes
> / < = octave up/down
